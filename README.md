#munch
Munch is a simple nutritional search engine. It is built using the OpenFoodFacts API.

#Searching
First, search your food/item/product in the search query.
Then, find your food/item/product in the library.

#Tracking
Using the tracker, you can track your calories locally.
First, select the date.
Second, start tracking your items by clicking "Track" when searching.
Third, set a goal for yourself. Set your calories and pick whether you want to get over or under that goal.
You can use the calendar heatmap to show how well you did over a one-month period.

#Favorites
If you have a food/item/product that you believe you will need to access on a regular basis, click the ♥️ to favorite it for later use (tracking).
